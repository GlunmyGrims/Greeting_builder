# Greeting Builder

A lightweight, highly customizable greeting builder built entirely with **JavaScript**.

## How to Run

1. Open the project files in your preferred code editor.
2. Modify the testing variables directly in the script to fit your needs.
3. Run the project in your terminal:

```bash
node greeting_builder.js
```

> **Tip:** This project is designed to be easily extensible. Feel free to adapt it for chat bots, CLI tools, or any creative application you can imagine!

---

## Why is it helpful?

It provides a simple, straightforward logic to greet anyone dynamically. With a few modifications, it can adapt to different times of the day, specific user contexts, and help create a more personalized and comfortable user experience (UX/UI).

---

## The Tech Behind It

* **Language:** Pure JavaScript (Vanilla JS) — no external dependencies or complex frameworks required.
